# publish-xhs-douyin

把做好的竖屏/横屏视频自动发布到 **小红书** 和 **抖音** 的 web 创作者后台，
通过 [Claude Code](https://claude.com/claude-code) + Claude-in-Chrome 驱动。

这是一份 **battle-tested 的操作手册**，不是一键脚本 —— 两个平台的创作者后台都用了
难伺候的富文本编辑器和异步下拉，真正的价值在于把踩过的坑写死在流程里。

## 它解决什么

浏览器自动化发视频，卡点从来不是"点哪个按钮"，而是：

| 坑 | 现象 | 手册里的解法 |
|---|---|---|
| 大文件进不去创作者页 | 文件选择器无法用代码填，CSP/Local Network Access 又挡死页内 fetch | `window.name` 跨域接力（顶层导航不受 CSP 管） |
| 页面来之不易时不能刷新 | 风控域黑洞期间 SPA 只偶尔挂载得起来，一导航就回不来 | IndexedDB 存 Blob 跨标签传，工作标签全程不动 |
| 话题看着对其实是纯文本 | 真话题和纯文本 `#xx` 同色同粗、innerText 一致 | 只认 `[data-mention]` 属性；chip 是原子的，删残留要用 Range 精确选中 |
| 抖音封面槽有两个 | 只传一张会挂「横/竖双封面缺失」，且信息流露出的是竖封面 | `make_covers.py` 一次出竖 3:4 + 横 4:3 |
| 定时时区不一致 | 小红书输入框语义即北京时间，抖音用浏览器本地时区 | 分别处理，提交后回列表页核对 |
| 小红书章节只有一次机会 | 发布后入口被锁，改章节要重传整个视频 | 章节必须在首发时设 |
| 抖音封面注入后竖槽变黑图 | 一次性给页面上全部 5 个 image input 派发 `change`，竖槽会被冲成视频首帧纯黑 | **一次只灌一个槽**。Windows + Claude for Chrome 下这样注入可全自动跑通；macOS/Codex 侧仍退回人工交接 |
| 风控域黑洞期一切变慢 | 话题下拉转 1–3 分钟、开关点不动、提交转 90 秒 | 退格重触发 / 推荐话题 chips / JS 派发 5 连鼠标事件 / 用列表计数增量核验 |
| 标题悄悄被截断 | 小红书上限 20 字、抖音 30 字 | 同一系列两边标题分别裁，写文案时就按 20 字准备 |

## 用法

在 Claude Code 里把这个目录放进 `~/.claude/skills/`，然后：

```
把这个视频发到小红书和抖音，定时北京时间 7/28 晚上 8 点
```

Claude 会读取 `SKILL.md` 并按流程执行。需要人工介入的地方（登录、发布确认，以及
**macOS/Codex 环境下的抖音封面上传**）它会停下来问。Windows + Claude for Chrome 下双封面可全自动，
见 SKILL.md §1 步骤 4。多期系列（如 7 期隔天定时）也能一次交代完，见 SKILL.md §2.2。

### 双封面生成

```bash
python3 scripts/make_covers.py --video 成片.mp4 --t 24.5 --bias 0.72 \
  --title "标题" --sub "副标题" --tag "小标签" --outdir final/
```

产出 `封面图-竖3x4.jpg` (1242×1656) 和 `封面图-横4x3.jpg` (1440×1080)，
两版都满幅铺图（竖版标题叠上三分之一，横版叠下三分之一），可读性靠渐变压暗而非色块。

`--t` 选片尾标题淡入之前的一帧；`--bias` 按主体水平位置给（3:4 满幅要从 16:9 裁掉大半宽度）。
